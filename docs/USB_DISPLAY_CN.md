# USB 5 寸扩展副屏（NexusMonitor 2.2.0 开发分支）

## 目标与边界

USB 5 寸屏使用 ESP32-P4 与 Windows IDD USB Graphic 驱动。驱动安装后由 Windows 创建扩展显示器；NexusMonitor 不自行编码 JPEG、不直接占用 USB 接口、不实现第二套 USB 帧传输协议。

本版新增的是 Electron 独立输出窗口与管理页面。设置页位于「图灵副屏」下方的「USB 5 寸副屏」，二者共享硬件快照/天气数据，但各自有独立显示路径。

**本版不控制 5 寸屏物理背光。** 用户已经确认屏幕侧边拨动按钮可逐级调节亮度，但现有 USB IDD/固件资料尚不能证明存在标准 USB 亮度命令。后续需要读取 ESP32-P4 固件与 USB 控制接口后再决定是否实现；在此之前不伪装成真正背光调节。

## 管理页面

- 获取 Electron `screen.getAllDisplays()` 返回的显示器列表，包括 id、主屏标志、逻辑分辨率、桌面坐标和缩放因子。
- 管理页首次发现时可提示/选定目标屏并保存显示器 id；2.2.0 启动恢复只使用该保存 ID，不在启动阶段盲目回退到其他非主显示器。
- 启动时创建独立、无边框、隐藏任务栏且无阴影的 BrowserWindow，直接使用目标显示器的完整 `bounds` 铺满显示；不调用 Electron 原生全屏切换，避免 Windows 在负桌面坐标或混合 DPI 布局下重新定位窗口。关闭只关闭 NexusMonitor 输出窗口，不改变 Windows 的扩展桌面设置。
- 目标显示器被移除时自动关闭输出窗口；若它是已保存目标，则等待同一 ID 重新枚举后再恢复；拓扑变化时刷新显示器列表并更新窗口 bounds；副屏位于主屏上方/左侧时保留负 `x/y`，不把逻辑坐标乘以缩放因子。
- 2.2.0 在应用启动时、HardwareService 启动之前就尝试按保存 ID 打开 USB 输出窗。显示器枚举较慢时在 display-added/topology change 时重试，不猜测错误屏幕。输出窗口仍根据已保存 `usbDisplayMode` 展示上次模式。
- 输出窗口加载 `?usb-display=1`，主界面不会在副屏窗口重复挂载 Turing 页面或启动第二个串口写入者。

## 内容模式

2.1.7 对 960×540 / 5 英寸输出重新做了视觉层级，不再复用桌面小字号：硬件监控采用大号 CPU/GPU 环形负载仪表、温度/功耗读数、彩色状态条、网络实时曲线和网格背景；天气时钟采用大时间、大温度并单独突出 US AQI。

1. **硬件监控**：订阅现有 `telemetry:update`，显示 CPU/GPU、内存、磁盘、物理网卡收发速度。无传感器值显示 `—`。
2. **静态壁纸**：从本机选择 JPG/JPEG/PNG/WEBP/BMP 图片。
3. **GIF 壁纸**：选择本机 GIF，使用 Chromium 原生 GIF 动画。
4. **天气时钟**：复用主应用已缓存的天气，不增加重复天气 API 请求，时钟每秒刷新。
5. **视频播放**：选择本地 MP4/M4V/WebM，MOV 是否可播取决于实际视频编码；不做额外转码。

图片可选「铺满裁切」或「完整显示」。图片读取由主进程负责，支持文件最大 80 MiB；视频路径只允许上述扩展名。静态/GIF 图片可额外选择本地 MP3/WAV/M4A/AAC/OGG/FLAC 背景音乐，设置音量和循环。

QQ 音乐：本版不直接抓取或代理 QQ 音乐音源。Windows 可通过 SMTC/QQMusic 客户端控制做后续联动研究，但 QQ 音乐面向个人桌面应用的稳定公开 OpenAPI 并不是本项目可以无条件依赖的接口，因此本版优先保证本地音频。


## 2.2.0 非视频模式的全局音乐控件

monitor、static、gif、weather-clock 四种非视频输出模式在屏幕角落增加共享迷你 MP3 播放控制层；video 模式刻意不显示。控制层只订阅主窗口的 Music Service 并发送 IPC 命令，不在 USB 输出 Renderer 内创建第二个音频元素。static/GIF 模式若配置了旧的独立背景音，当本地音乐库选中歌曲后背景音让位，避免同时播放两路音频。播放器音量独立于 Windows 系统音量。该浮层的位置、触摸尺寸与天气画面避让仍须在实际五寸屏上验证。

## 图灵昼夜自动亮度

复用现有 HardwareService `/api/turing/brightness` 与 Electron `turing:brightness` IPC，不增加第二个串口写入者。默认关闭；开启后按 Windows 本地时间判断白天/夜间亮度，连接时立即应用、每 30 秒复核，并在设置改变或重新连接后重新应用。

默认参数：白天 08:00 / 70%，夜间 20:00 / 25%。支持跨午夜时间段、百分比 0–100 裁剪。自动模式开启时禁用手动亮度滑块；关闭自动模式后恢复手动设置。

该页面目前随主窗口 Renderer 常驻（隐藏时仍挂载），因此切换其他页面或关闭主窗口但保留应用进程时，定时逻辑不会因离开图灵设置页而停止。若应用完全退出，自动调节自然暂停；下次启动连接成功后重新按当前时间应用。

## Windows 使用步骤

1. 安装/启用兼容的 xfz1986 USB Graphic IDD 驱动，并在 Windows「设置 → 系统 → 屏幕」启用「扩展这些显示器」。
2. 启动 NexusMonitor 2.2.0，进入「设备输出 → USB 5 寸副屏」。
3. 在目标显示器下拉框选择 5 寸屏对应的显示器；如有疑问按 Windows 显示设置里的编号/相对位置匹配，不要只依赖 EDID 名称。
4. 选择内容模式，再点击「启动副屏」。退出窗口可点击「关闭副屏」。
5. 2.2.0 在成功选择目标显示器并启动一次后，后续应用启动会自动恢复该副屏。切换目标屏时重新保存目标 ID。图灵屏昼夜亮度在「图灵副屏」页配置；首次开启后要确认设备已连接，并观察真实背光是否按当前时间改变。

## 已知限制与验收

- Electron 的显示器 id 由系统枚举；如果 Windows/驱动重装导致 id 改变，需要在管理页重新选择。
- 某些 USB Graphic 虚拟显示设备的 EDID 可能显示为通用/模板显示器，不能仅用显示器名称匹配。
- Windows 逻辑分辨率与面板物理分辨率不同；无边框输出窗口跟随 Windows 当前显示模式，本版不修改显示模式，也不强制改为 540×960 或 1920×1080。
- 5 寸屏物理背光调节尚未接入；屏幕侧边拨动按钮仍然可以本机操作。
- 图灵自动亮度须在 COM3/目标串口真实连接、且原厂 `UsbMonitor.exe` 已关闭时做实机验收。
- 需要在目标 Windows 上验证 `npm.cmd run test:main`、`npm.cmd run build:renderer`、Storage tests、.NET Release、NSIS、显示器热拔插、负坐标与混合缩放定位、相邻显示器边界无溢出、各内容模式播放和图灵定时亮度。
